# Документация `@feugene/granum`

> Статус: **реализовано**, версия 0.2.0; этапы 0–8 плана выполнены 2026-09-26.
> Преемник `@feugene/unocss-preset-granular` (далее — «пресет v1», не изменяется).

Granum — конвейер сборки гранулярных UI-пакетов: JS/Vue-компоненты, их стили,
дизайн-токены и темы проходят один путь от исходников провайдера до дистрибутива
приложения. Оркестратор — собственный Vite-плагин, а не конфиг UnoCSS; движок
утилит выбирает приложение и передаёт инстансом, а манифест каждого пакета
записывает, чей движок отфильтровал его список классов.

Визуальная схема конвейера (блоки, потоки данных, ожидаемый результат) —
[`architecture-pipeline.html`](./architecture-pipeline.html): откройте файл в
браузере.

## Порядок чтения

1. `spec.md` §1–§4 — зачем и из чего состоит.
2. `invariants.md` — целиком, один раз.
3. `decisions.md` — чтобы не переоткрывать закрытые вопросы.
4. `plan.md` — с какого этапа начинать.
5. Остальные разделы `spec.md` и `manifest.md` — по мере работы над блоком.

## Соглашения

- Идентификаторы требований: `C-*` контракт, `B-*` сборка провайдера, `M-*` манифест,
  `R-*` резолвер, `E-*` движок, `A-*` плагин приложения, `T-*` токены и темы,
  `RT-*` рантайм, `D-*` диагностика, `N-*` нефункциональные. Инварианты — `INV-*`,
  решения — `ADR-*`.
- Слова **MUST / MUST NOT / SHOULD / MAY** — по RFC 2119.
- Язык документации — русский; идентификаторы, имена полей и сообщения ошибок —
  английские.
- Ссылки на пресет v1 даются как «SPEC v1 §N» и указывают на
  `packages/unocss-preset-granular/docs/SPEC.md` репозитория `unocss-preset-granular`.
