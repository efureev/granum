# Замер веса CSS/JS

> 🇬🇧 English version: [`../en/measuring-weight.md`](../en/measuring-weight.md).

Три стенда в `apps/` отвечают на вопрос «сколько стоит подключить один
компонент» и «что из уехавшего в дистрибутив не используется».

| Стенд | Что в нём | Зачем |
|---|---|---|
| `bench-zero` | голый Vue, ни granum, ни провайдера | знаменатель: цена пустого приложения с той же обвязкой |
| `bench-one` | плагин granum и один `XhPanel` из фикстуры `heavy` (граф тянет ещё четыре), обрезка выключена явно (`pruneTokens: { mode: 'off' }`) | подопытный: полная цена компонента поверх фундамента |
| `bench-pruned` | то же с обрезкой — умолчанием granum (`pruneTokens: { mode: 'on' }`) | эффект обрезки токенов |

Обвязка стендов совпадает во всём, кроме плагина и чанк-группы провайдера:
только тогда разница дистрибутивов — цена библиотеки, а не сборочных
настроек. `App.vue` стендов не содержит ни одного собственного класса —
иначе слой `utilities` перестанет быть атрибутируемым.

## Команды

```bash
yarn build:all
yarn sizes            # bench-one против bench-zero, bench-pruned против bench-one
yarn sizes:check      # строгая сверка всех стендов с expected-budget.mjs
yarn compare:css      # множество CSS-правил bench-one равно снапшоту пресета v1
yarn compare:js       # JS bench-one побайтно равен сборке без плагина
```

Роли ассетов — `vue`, `pkg` (чанки провайдера), `css` (весь CSS granum одним
файлом), `entry`. Ассет, не подошедший ни под одну роль, роняет отчёт:
корзины «прочее» нет намеренно. Слои берутся из отчёта сборки: плагин режет
собранный ассет по блокам `@layer` после минификации (`sizesSource: 'bundle'`),
размеры эмиссии до минификации лежат рядом в `emissionSizes`.

Достижимость токенов считается по дистрибутиву: корень — ссылка вне значения
custom property (правило CSS, литерал в JS), дальше — по значениям
объявлений. Стенд с обрезкой обязан показать «мёртвый груз 0».

## Что гейтится

Порога на байты нет: gzip невоспроизводим между средами, а порог с потолка
краснеет на честном росте. `expected-budget.mjs` стенда фиксирует булевы
факты и сверяется в обе стороны — пропавшее ожидаемое расхождение такое же
событие, как новое:

- состав ролей ассетов;
- классы без правила в отчёте (`shadow-legacy` — намеренная фикстура);
- токены без объявления;
- режим обрезки и `maxUnused: 0` для `bench-pruned`;
- движок не попал в клиентский бандл.

Байты лежат в `hints` и печатаются рядом с фактом как ориентир.

## Соседний стенд: что лишнего

`bench-*` отвечают на вопрос «сколько весит», `apps/dist-audit` — на вопрос
«что из пакета осталось». Это приложение из одного `div` и одного компонента
поверх миниатюрной дизайн-системы `fixtures/mini-ds-package`: два компонента,
тема с двумя режимами, десять токенов с намеренным мёртвым грузом.

```bash
yarn workspace @granum-apps/dist-audit audit:dist
```

Аудит читает манифест пакета, собранный CSS и JS и называет поимённо: код
невыбранного компонента (его выбросил tree-shaking), его классы (их не взяла
селекция), токены, снятые обрезкой, и токены пакета в дистрибутиве, до которых
не дотянуться. Последних быть не должно — на этом стенд и падает.

## Сверка с пресетом v1

`apps/bench-one/v1-snapshot.css` — CSS того же стенда, собранного
`@feugene/unocss-preset-granular` 0.16.1. `compare-css.mjs` нормализует оба
вывода в множество `{ контекст, селектор, объявления }` (обёртки `@layer`
снимаются, порядок не важен) и сравнивает; допустимые расхождения
перечисляются в `expected-compare.mjs`. Их два, и оба ожидаемые: у v1 есть
`@keyframes granularity-spin`, которого granum без `animate-spin` не
эмитирует, а preflight (`*`, `:before`, `:after`, `::backdrop`) у granum
объявляет больше переменных — словарь wind3 шире. Правил 58 у v1 и 57 у
granum. Значение `--xh-fg-boost` в снапшоте приведено к фикстуре: пресет
переносит CSS фундамента как есть.
