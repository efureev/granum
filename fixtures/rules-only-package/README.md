# `@granum-fixtures/rules-only`

Провайдер **без компонентов**: только правила движка утилит. Так выносят правила
приложения в отдельный пакет — движок приложения остаётся ванильным, отпечаток
его словаря совпадает с отпечатками пакетов, и сборка идёт быстрым путём, без
пересчёта классов.

| Что | Где видно |
|---|---|
| компонентов нет, корневого barrel нет | `components: []`, `indexEntry: false` |
| правила едут модулем, а не в JSON манифеста | `engine.module`, `dist/engine.js` |
| пакет собран ванильным движком своего диалекта | отпечаток в манифесте равен `windEngine().vocabulary` |
| данные правил встроены в модуль | `src/palette.json` внутри `dist/engine.js` |
| приложение того же диалекта получает правила, пересчёта нет | [`app-rules`](../../apps/app-rules) |

Правила — на словаре wind: статическое `brand-logo` и регэксп `brand-pad-<n>`.
Как собрать такой пакет — раздел «Провайдер только с правилами» в
[руководстве автора провайдера](../../docs/ru/authoring-providers.md).
