# `@granum-fixtures/plain`

Провайдер **без словаря утилит вовсе**: вся отделка — собственный CSS
компонентов и токены темы. Блок `engine` пакет не объявляет, и в манифест
уезжает `dialect: null, vocabulary: null`.

Зачем такой стенд: диалект в манифесте — факт о происхождении списка классов, и
для пакета без классов этот факт пустой. Приложение обязано прочитать его любым
движком и без пересчёта — что и проверяет
[`app-atoms`](../../apps/app-atoms), где он стоит рядом с пакетом чужого
диалекта в одной сборке.

Читатель манифеста следит за согласованностью в обе стороны: `dialect: null` при
непустых `classes`, `safelist` или `engine.module` — ошибка
`dialect-without-classes`, потому что список классов кто-то всё-таки
отфильтровал, и манифест обязан сказать, кто.
