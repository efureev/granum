# `@granum-engines/atoms`

Игрушечный движок словаря `granum-fixtures/atoms@1` — реализация
`GranumEngine` с нуля, на публичных хелперах ядра и без единой строчки UnoCSS.

Он здесь не ради демонстрации. Пока единственная реализация интерфейса живёт в
нашем же репозитории рядом с ядром, «движок сменный» остаётся утверждением без
доказательства: контракт мог незаметно опереться на детали
`@feugene/granum-engine-wind`. На этом движке собирается фикстура
[`@granum-fixtures/atoms`](../atoms-package) и работает приложение
[`app-atoms`](../../apps/app-atoms).

## Словарь

| Имя | CSS |
|---|---|
| `atom-stack` | `display:flex; flex-direction:column` |
| `atom-inline` | `display:flex; flex-direction:row; align-items:center` |
| `atom-fill` | `flex:1 1 0%` |
| `atom-gap-<n>` | `gap:<n × 4>px` |
| `atom-pad-<n>` | `padding:<n × 4>px` |
| `atom-bg-[…]` | `background:…` |

Ни одно имя не пересекается с preset-mini — расхождение диалектов видно сразу, а
не в виде «похоже, но не то».

## Что он обязан объявить

`dialect` — имя словаря, по нему granum решает, грузить ли правила пакета.
`vocabulary` — отпечаток фактического набора правил, посчитанный
`vocabularyFingerprint` из `@feugene/granum/engine`: правило, переданное фабрике,
диалект не меняет, а отпечаток меняет, и приложение с таким правилом пересчитает
классы пакетов вместо того, чтобы поверить их манифестам.
