Значения компонентов у темы

Дизайн-система объявляет имена токенов, темы дают значения. «Камень» — базовая тема пакета, «Мох» — её копия, «Угли» — наследник, «Прилив» — тема из отдельного пакета, «Риф» — своя тема приложения поверх «Мха».
