# `apps/bench-pruned`

Тот же стенд, что `bench-one`, отличающийся **одной строкой конфига**:

```ts
pruneTokens: { mode: 'on' }
```

Пара `bench-one` → `bench-pruned` и есть измерение эффекта обрезки. Всё
остальное в двух сборках обязано совпадать, иначе разница перестаёт быть
разницей обрезки.

## Результат (gzip)

```
роль         bench-one  bench-pruned        Δ
css              2 441         1 661     −780
entry              756           758       +2
pkg              2 093         2 093        0
vue             23 618        23 618        0
```

Токены в дистрибутиве: **117 → 49 объявленных, мёртвый груз 68 → 0.**

## Почему `appSources` обязателен

granum видит компоненты провайдера по манифестам и **не видит разметку
приложения**. Утилита `bg-[var(--xh-accent)]`, написанная в `App.vue`, без
`appSources` для обрезки не существует, и её токен уедет из CSS при зелёной
сборке. В этом стенде разметка без утилит, но строка стоит: стенд заодно
документирует обязательный порядок внедрения — `report` → посмотреть план в
`granum-report.json` → `on`.

## Что охраняет `expected.mjs`

| проверка | что было бы без неё |
|---|---|
| `--xh-z-dropdown` уцелел | имя собирается в рантайме из общего модуля — держит только `dynamicTokens` у `XhOverlay` |
| `--xh-alert-duration` уцелел | читается из JS по имени, `var()` нет; литерал в чанке попадает в `consumes` манифеста |
| `--xh-fg-boost` и `--xh-elevated-fg` уцелели | пара «объявлен только в светлой ↔ нужен только тёмной»; множество сохранённых глобально по темам |
| `--xh-invalid-brd` уцелел | роль ссылается на роль — замыкание идёт по ссылке |
| `@supports not` на месте | фолбэк производной роли лежит внутри at-rule |
| `box-sizing` на месте | `base.css` не обрезается |

И четыре `absent` — что обрезка действительно убрала: сырая палитра, токены
невыбранного компонента, неиспользуемые ступени шкал. `expected-budget.mjs`
требует `tokens.maxUnused: 0`.

## Команды

```bash
yarn workspace @granum-apps/bench-pruned build
yarn workspace @granum-apps/bench-pruned verify
node scripts/report-css-budget.mjs --stand bench-pruned --baseline bench-one
```
