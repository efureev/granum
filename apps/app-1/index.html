granum · демо-стенд app-1

Один компонент из манифеста

Приложение выбирает XTest1 из пакета @granum-fixtures/simple. Весь CSS собирается по манифесту: каскадные слои, собственный CSS компонента, утилиты из его шаблона и из разметки приложения.

Что видно

  • Крупный жирный красный текст — @apply из <style> компонента. Директиву раскрыла ещё сборка пакета, в приложение она не доезжает.
  • Рамка в цвет текста: цвет границы --brd компонент ждёт от приложения, а здесь его нет. granum doctor предупреждает token-undefined, и браузер берёт currentColor.
  • Ширину колонки задаёт max-w-3xl из разметки самого приложения.

Проверка: yarn workspace @granum-apps/app-1 verify; каскад и HMR в браузере — yarn e2e.
