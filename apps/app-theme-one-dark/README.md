# `app-theme-one-dark`

Пара к [`app-theme-one-light`](../app-theme-one-light/README.md): та же кнопка `VdButton`, та же тема
«Камень», обрезка включена, но только режим `dark`. В CSS — токены кнопки и их ссылки со значениями
тёмного режима и ни пары, ни схемы, ни значений светлого. Что и как проверяется — в README пары.

```bash
yarn workspace @granum-apps/app-theme-one-dark build
yarn workspace @granum-apps/app-theme-one-dark verify
```
