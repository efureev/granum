# `app-dialects`

Стенд ветки **«другой диалект, наборы разошлись»** из таблицы решений §8
[ТЗ движка](../../docs/spec-engine.md).

Пакет `@granum-fixtures/heavy` собран движком с доп-правилами — словарь
`unocss/preset-mini+granum@66`. Приложение берёт `miniEngine({ extraRules: false })`,
то есть `unocss/preset-mini@66`: это другой словарь, в нём нет ни `divide-y`, ни
`space-x-*`, ни `tabular-nums`.

Что обязано произойти:

1. granum не верит списку классов манифеста и пересчитывает его своим движком;
2. `divide-y` при пересчёте не находится — правила для него нет;
3. класс не исчезает молча: он назван в `lost` отчёта, подан движку и виден в
   `unmatched` с источником `@granum-fixtures/heavy`;
4. доктор говорит об этом двумя предупреждениями: `provider-dialect-mismatch`
   и `provider-classes-dropped`.

Починка для разработчика ровно одна из двух: поставить движок диалекта пакета
либо добавить правило в фабрику своего. Именно это и печатает `granum why-css divide-y`.
