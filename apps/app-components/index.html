Канал JS

Компонент импортируется из virtual:granum/components, который granum собирает по селекции. В селекции оба компонента пакета @granum-fixtures/mini-ds, разметка берёт один, и второй вырезает tree-shaking. CSS идёт по селекции, поэтому стили обоих в дистрибутиве есть.

Что видно

  • Карточка — XxCard: рамка и поверхность из собственного CSS пакета, отступ — утилита p-[var(--xxx-space-2)], общая у пакета и приложения.
  • Объявления модуля для TypeScript плагин пишет сам — в src/granum.d.ts.

Проверка: yarn workspace @granum-apps/app-components verify
