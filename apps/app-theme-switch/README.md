# `app-theme-switch`

Пример: как собрать несколько тем в одно приложение и переключать их в браузере.
Две темы приходят из пакета — «Бумага» (`paper`) и «Чернила» (`ink`) из
[`@granum-fixtures/themes`](../../fixtures/themes-package/README.md), — третья,
«Песок» (`sand`), своя у приложения. Компоненты — из
[`@granum-fixtures/themed-ds`](../../fixtures/themed-ds-package/README.md).

```bash
yarn build && yarn build:fixtures          # пример работает с собранными пакетами
yarn workspace @granum-apps/app-theme-switch dev
yarn workspace @granum-apps/app-theme-switch build && yarn workspace @granum-apps/app-theme-switch verify
```

## Что смотреть

| Файл | Что в нём |
| --- | --- |
| `granum.config.ts` | темы сборки — `themes`: основная `paper` (`default: true`), дополнительные `ink` и своя `sand`; режимы — у каждой свои |
| `src/themes/sand.ts` | своя тема приложения — объект `GranumAppTheme` с полными данными; `extends: 'paper'` берёт токены компонентов «Бумаги» |
| `vite.config.ts` | `themeScript: true` — скрипт до первого кадра в `<head>`: сохранённый выбор на корне раньше, чем страница нарисуется |
| `src/main.ts` | общий лист `virtual:granum.css`; листы дополнительных тем не импортируются |
| `src/theme.ts` | `createThemeController(manifest)` поверх манифеста сборки `virtual:granum/themes` |
| `src/App.vue` | переключатель темы (`setTheme`) и режима (`setMode`), состояние через `subscribe`, острова с парой на поддереве и `loadThemeSheet` для их листов |

## Как это работает

**Основная тема** — в общем листе и под `:root`: её режим по умолчанию действует
без атрибута, другой режим включает пара `data-theme="paper-dark"`.

**Дополнительная тема** — своим листом. Сборка выпускает его ассетом
(`granum-theme-ink-<хеш>.css`), адрес кладёт в манифест тем, а в HTML ссылки нет:
пока тему не выбрали, страница за неё не платит. `setTheme('ink')` сначала
загружает лист и только потом ставит пару `ink-light` — без листа элемент получил
бы значения основной темы под чужим именем. Если лист не загрузился, контроллер
остаётся в прежней теме.

**Режим при смене темы** — заданный, иначе одноимённый текущему, иначе первый той
же схемы, иначе режим по умолчанию темы: из `ink-dim` «Песок» откроется тёмным.

**Выбор запоминается** в `localStorage` (ключ `granum-theme`: имя режима у
основной темы, `<тема>-<режим>` у дополнительной). После перезагрузки скрипт до
первого кадра ставит пару и ссылку на лист с `blocking="render"` — страница
сразу в выбранной теме, без мигания основной.

**Остров** — пара на поддереве (`<div data-theme="sand-dark">`): тема и режим на
своём элементе, пока корень в своей. Лист дополнительной темы острову грузит
`loadThemeSheet`, пару страница ставит после загрузки.

## Проверка

- `expected.mjs`: основная тема в общем листе, листы `ink` и `sand` — отдельными
  ассетами и не подключены страницей, их адреса — в манифесте и в скрипте до
  первого кадра.
- `yarn e2e` (сценарий «пример переключения тем»): острова в своих темах, выбор
  темы и режима, перенос схемы режима, выбор после перезагрузки с
  заблокированным JS приложения — его ставит скрипт до первого кадра.
