# `app-atoms`

Приложение на движке, которого в granum нет: [`@granum-engines/atoms`](../../fixtures/atoms-engine)
реализует `GranumEngine` с нуля, на публичных хелперах ядра и без единой строчки
UnoCSS. Это и есть доказательство, что движок сменный, а не обещание.

В одной сборке два пакета разной природы:

| Пакет | Диалект | Что показывает |
|---|---|---|
| [`@granum-fixtures/atoms`](../../fixtures/atoms-package) | `granum-fixtures/atoms@1` | тот же словарь, что у движка: правила пакета из модуля загружаются, `atom-frame` попадает в CSS |
| [`@granum-fixtures/plain`](../../fixtures/plain-package) | `null` | пакет без словаря вовсе: работает с любым движком, пересчёта не требует |

Правило приложения `atom-hairline` передано **фабрике движка**, а не конфигу: у
конфига поля для правил нет и не будет. Из-за него отпечаток словаря приложения
отличается от записанного в манифесте пакета, поэтому granum пересчитывает
классы пакета своим движком — и получает тот же набор. Так выглядит измеренная
совместимость: ни `lost`, ни `gained`, ни одного предупреждения.
