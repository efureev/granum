# `app-rules`

Приложение, которое берёт свои правила утилит из пакета, а не передаёт их фабрике
движка. Пакет — [`@granum-fixtures/rules-only`](../../fixtures/rules-only-package),
провайдер без компонентов: только модуль правил.

Зачем так. Правила, переданные фабрике (`windEngine({ rules })`), меняют отпечаток
словаря движка приложения, и granum на каждой сборке пересчитывает классы всех
пакетов из их файлов. Правила в пакете оставляют движок ванильным: отпечатки
совпадают, списки классов манифестов принимаются как есть.

| Что | Где видно |
|---|---|
| правила пакета загружены: диалекты совпали | `providers[].rulesLoaded` в отчёте, `.brand-logo` и `.brand-pad-3` в CSS |
| быстрый путь: пересчёта нет | `providers[].classes: 'manifest'`, `reason: 'none'` |
| словарь wind на месте | `.p-6` в CSS |

```bash
yarn workspace @granum-apps/app-rules build
yarn workspace @granum-apps/app-rules verify
```
