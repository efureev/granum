# granum

Конвейер сборки гранулярных UI-пакетов. Пакет-провайдер публикует компоненты, их
стили, дизайн-токены и темы вместе с машинно-порождённым `granum.manifest.json`;
приложение вычисляет одну селекцию компонентов и кормит из неё три канала —
JavaScript, CSS с каскадными слоями, токены и темы. Движок утилит выбирает
приложение, а не granum: он приходит инстансом, объявляет словарь имён классов,
на котором говорит, и каждый манифест записывает, чей движок отфильтровал его
список классов.

Преемник `@feugene/unocss-preset-granular`. Статус: **1.0.0** — все десять этапов
плана выполнены, CSS стенда замера совпадает с пресетом v1, а контракт
заморожен: меняется только мажором (§18 ТЗ). Отпечаток словаря движка
сознательно вне этого обещания — пересчёт классов это штатный путь.

## Репозиторий

| Путь | Назначение |
|---|---|
| `packages/granum` | пакет: `.`, `./contract`, `./engine`, `./build`, `./vite`, `./node`, `./runtime`, `./codegen`, CLI `granum` |
| `packages/granum-engine-wind` | референсный движок утилит: вендоренный форк UnoCSS 66.7.5 за инстансом `GranumEngine` |
| `fixtures/*` | референсные пакеты-провайдеры и игрушечный движок второго словаря |
| `apps/*` | интеграционные приложения и стенды замера веса (с этапа 5) |
| `docs/` | техническое задание, инварианты, формат манифеста, решения, план |
| `docs/en`, `docs/ru` | руководства, зеркальные |
