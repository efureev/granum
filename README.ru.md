# granum

Конвейер сборки гранулярных UI-пакетов. Пакет-провайдер публикует компоненты, их
стили, дизайн-токены и темы вместе с машинно-порождённым `granum.manifest.json`;
приложение вычисляет одну селекцию компонентов и кормит из неё три канала —
JavaScript, CSS с каскадными слоями, токены и темы. Движок утилит — сменный
адаптер внутри CSS-канала.

Преемник `@feugene/unocss-preset-granular`. Статус: **этап 0 — каркас
репозитория**; пакет отдаёт свои точки входа, но поведения в них ещё нет.

## Репозиторий

| Путь | Назначение |
|---|---|
| `packages/granum` | пакет: `.`, `./contract`, `./engine`, `./build`, `./vite`, `./node`, `./runtime`, `./codegen`, CLI `granum` |
| `fixtures/*` | референсные пакеты-провайдеры (с этапа 4) |
| `apps/*` | интеграционные приложения и стенды замера веса (с этапа 5) |
| `docs/` | техническое задание, инварианты, формат манифеста, решения, план |
| `docs/en`, `docs/ru` | руководства, зеркальные |
